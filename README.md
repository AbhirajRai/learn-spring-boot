# Learn Spring Boot

A hands-on Spring Boot learning repository covering the fundamentals of building Java-based web applications with Spring Boot.

## 📚 What I Learned

This repository contains practical examples and exercises covering:

- Spring Boot project setup
- Spring Boot application structure
- Dependency Injection
- Spring Beans
- Component Scanning
- Application Configuration
- REST API fundamentals
- Controllers and Request Mapping
- Service Layer concepts
- Maven-based project management
- Running and testing Spring Boot applications

## 🛠️ Technologies Used

- Java
- Spring Boot
- Spring Framework
- Maven
- IntelliJ IDEA
